# plan_0001 - GM 테스터 기반 서사/상태 불일치 탐지 및 리모트 BE-router 연동

## User Requirements

- 테스터를 돌려서 서사적/상태적 불일치를 빠르게 찾고 수정 가능한 루프를 구축해야 함.
- 로컬 검증뿐 아니라 리모트 서버의 BE-router를 호출하는 검증 경로가 필요함.

## Goal

- GM 검증 스크립트를 기준 데이터(상태)와 서사 출력(내러티브)의 정합성 검증까지 확장한다.
- 테스트 타깃을 `local`/`remote` 2개 모드로 표준화하여 BE-router 경유 경로를 재현 가능하게 만든다.

## Scope

- In:
  - `scripts/verify_gm_flow.py` 확장 (검증 포인트 추가)
  - `scripts/` 내 공통 HTTP 클라이언트/설정 분리 (`TARGET_ENV`, `BE_ROUTER_BASE_URL`)
  - 문서/실행 절차 갱신
- Out:
  - GM 엔진 로직 전면 리팩터링
  - 운영 모니터링 대시보드 구축

## Implementation Plan

- Step 1: `verify_gm_flow.py`에 상태 스냅샷 비교(턴 전/후 hp, location, relation) 로직 추가.
- Step 2: `--target {local,remote}` 인자 도입, remote 모드에서 `BE_ROUTER_BASE_URL` 사용.
- Step 3: 실패를 `NarrativeMismatch`, `StateMismatch`, `RouterContractMismatch`로 분류.
- Step 4: 상태 불일치가 발생한 턴의 요청/응답 payload를 아티팩트(JSON)로 저장.

## Unit Test Plan (must)

- What to test:
  - 타깃 선택(local/remote) 분기
  - 검증 실패 분류 로직
- Command:
  - `uv run pytest tests/test_rule_integration.py tests/test_llm_adapter.py`

## E2E Plan (must)

- How to run:
  - `uv run python scripts/verify_gm_flow.py --url http://localhost:8020 --session verify-session-001`
  - `uv run python scripts/verify_gm_flow.py --target remote --session verify-session-001`
- Validation:
  - 불일치가 없으면 PASS 리포트.
  - 불일치가 있으면 분류 코드 + turn_id + 재현 payload 출력.

## Done Criteria

- [ ] 서사/상태 불일치 자동 탐지 및 분류
- [ ] 실패 케이스 재현에 필요한 payload 아티팩트 생성
- [ ] docs/dev 문서 갱신
